# Currency-Converter💱 

A simple and fast **Currency Converter** built with **HTML**, **CSS**, and **JavaScript**, using live exchange rates from a free API.  
This tool allows users to convert between popular currencies such as USD, EUR, GBP, NGN, and JPY.

Perfect for beginners learning API calls, DOM manipulation, and interactive UI design.


## 🚀 Features

### 🔢 Core Features
- Convert between multiple currencies  
- Live exchange rates using a public API  
- Clean and responsive UI  
- Instant conversion with one click  

### 🌍 Supported Currencies
- USD — United States Dollar  
- EUR — Euro  
- GBP — British Pound  
- NGN — Nigerian Naira  
- JPY — Japanese Yen  

### 🎨 UI Features
- Simple and modern layout  
- Easy-to-use dropdowns  
- Clear conversion result display
